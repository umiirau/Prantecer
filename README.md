Консольный анализатор сетевого трафика (Автор: @faceroka)

Программа предназначена для мониторинга сетевых пакетов в реальном времени. Позволяет отслеживать весь входящий и исходящий трафик между ПК и роутером с указанием программ, генерирующих сетевую активность.

Примечание: Для работы требуется запуск от имени администратора (запрос прав происходит автоматически).
