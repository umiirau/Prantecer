Сетевой анализатор трафика
Автор: @faceroka

Программа предназначена для мониторинга сетевых пакетов в реальном времени. Позволяет отслеживать весь входящий и исходящий трафик между ПК и роутером с указанием конкретных программ, генерирующих сетевую активность.

ТРЕБОВАНИЯ И УСТАНОВКА

Для пользователей (запуск готового .exe):

Npcap Driver — обязателен для захвата сетевых пакетов в Windows. При установке обязательно отметьте галочку "Install Npcap in WinPcap API-compatible Mode".

Права администратора — необходимы для работы с сетевыми адаптерами и сокетами (запрос прав происходит автоматически при старте).

Для разработчиков (сборка проекта):

Установите необходимые NuGet-пакеты через терминал в папке проекта:

dotnet add package SharpPcap
dotnet add package PacketDotNet

Сборка в один автономный .exe файл: dotnet publish -c Release

Готовый исполняемый файл появится в папке: bin/Release/net8.0/win-x64/publish/
